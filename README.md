# Roblox-style Browser Experiments

This repository contains a small Roblox-inspired front page and two Blockverse browser experiences.

## Pages
- `index.html` — the home/discovery interface.
- `game.html` — the Blockverse build/play experience.
- `play.html` — the 3D experiences launcher.

## Run
Open `index.html` in a modern browser or publish the repository with GitHub Pages (Settings → Pages → Deploy from a branch → main → /(root)). The 3D pages may load browser libraries from public CDNs, so internet access is needed for those external dependencies.

This is an independent browser project and does not connect to Roblox accounts, Roblox servers, or the Roblox platform.
